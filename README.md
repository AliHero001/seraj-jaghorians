# سراج جاغوریان

وب‌سایت فارسی و راست‌چین خدمات اینترنتی سراج جاغوریان. این پروژه یک سایت ایستا است و برای ساخت آن به کتابخانهٔ جانبی نیاز نیست.

## ساخت سایت

به Node.js نسخهٔ ۱۸ یا جدیدتر نیاز است:

```sh
node src/build-site.mjs
```

فایل‌های آماده در پوشهٔ `dist/` ساخته می‌شوند. همین فایل‌ها را می‌توان روی هر میزبانی وب ایستا قرار داد.

## آزمایش

```sh
node --test tests/site-rendering.test.mjs
```

## صفحه‌ها

- خانه: `/`
- دربارهٔ ما: `/about/`
- خدمات: `/services/`
- بسته‌ها: `/packages/`
- سفارش: `/order/`
- تماس با ما: `/contact/`

دکمه‌های هر بسته پیام سفارش همان بسته را در واتساپ باز می‌کنند. محدودهٔ خدمات فعلی فقط جاغوری است.
